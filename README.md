# AI-Powered Dental Clinic Appointment Booking Chatbot

An interactive AI-powered chatbot developed for Dental Comfort / Miru Implant Centre using Python, Google Colab and Gradio.

The system allows users to explore dental services, check estimated prices and book appointments through a conversational interface.

## Features

- Interactive Gradio chatbot interface.
- Dental services and estimated pricing.
- Patient name and email collection.
- Dynamic available date selection.
- Available appointment time slots.
- Appointment summary and confirmation.
- Automated email confirmation.
- Google Calendar event creation.
- Excel-based appointment record management.

## Technology Stack

- Python
- Google Colab
- Gradio
- Google Calendar API
- Email Automation
- Pandas / Excel

## How It Works

1. User opens the chatbot.
2. User explores available dental services.
3. User selects a service for booking.
4. Chatbot collects patient details.
5. User selects an available date and time.
6. Chatbot generates an appointment summary.
7. User confirms the appointment.
8. Confirmation email is sent.
9. Appointment event is created in Google Calendar.
10. Appointment details are stored in Excel.

## Getting Started

1. Clone this repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Configure the required API credentials and integrations.
4. Run the notebook cells.
5. Launch the Gradio interface.

## Security

API keys, email credentials, Google service account credentials and private patient information are not included in this repository.

Configure credentials securely using Google Colab Secrets.
